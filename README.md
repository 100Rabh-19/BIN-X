# Smart Waste Sorter

The Smart Waste Sorter is an automated waste segregation project designed to identify and separate different categories of waste using sensors, computer vision, embedded control systems, and a motorized sorting mechanism.

The project follows a two-stage development approach. The initial prototype uses an Arduino-compatible controller, proximity and infrared sensors, a moisture sensor, a stepper motor, and a servo motor to demonstrate sensor-driven sorting. The advanced design extends this concept with a Raspberry Pi 5 for image capture and local AI inference, an ESP32-S3 for real-time sensor and actuator control, load cells for weight measurement, and a redesigned mechanical enclosure with four collection compartments.

The long-term objective is to develop a modular and maintainable waste segregation system with improved classification, automated routing, operational monitoring, and measurable sorting performance.

**Core technologies:** Python, Arduino/C++, Raspberry Pi 5, ESP32-S3, computer vision, embedded systems, sensor integration, motor control, CAD design, and IoT connectivity.

**Development status:** Prototype completed; advanced system under design and development. Specifications, component selection, schematics, and performance targets will be validated as the project progresses.
